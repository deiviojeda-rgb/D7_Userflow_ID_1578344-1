## Как запускать

Все команды — из корня репозитория, там, где лежит `README.md`.

```
$ python3 src/db.py

activity: 207640 строк
act: 207640 строк
newcomers: 20907 строк
cohorts: 90 строк
rice: 4 строк
```

Если видишь шесть строк с числами — база собирается. Сборка занимает пару секунд.

| Что нужно | Команда |
|---|---|
| выполнить все запросы файла | `python3 src/run_sql.py src/ex01.md` |
| только запросы под одним заголовком | `python3 src/run_sql.py src/ex01.md "Липкость"` |
| попробовать запрос, не записывая его в файл | `python3 src/run_sql.py -e "SELECT COUNT(*) FROM newcomers"` |
| посмотреть на числа графиком | `python3 src/chart.py "SELECT …" имя` → `src/charts/имя.html` |

Как устроен `.md`-файл с запросами — так же, как вчера: под заголовком вопроса строка `**Ответ:**`, под ней блок ```sql. `run_sql.py` печатает заголовок, твой ответ и результат запроса рядом. Строку `**Ответ:**` не переноси под блок — тогда `run_sql.py` её не увидит.

Выводит `run_sql.py` не больше 100 строк результата — остальное обрезает. Если строк больше, сгруппируй крупнее или добавь `LIMIT`.

## Шесть конструкций — примеры на сегодняшних данных

```sql
-- 1. SELECT … FROM … — взять поля
SELECT user_id, date, games, wins FROM activity LIMIT 5;

-- 2. WHERE — оставить нужные строки
SELECT COUNT(*) FROM newcomers WHERE wins0 = 0;

-- 3. ORDER BY — отсортировать
SELECT cohort, d0 FROM cohorts ORDER BY d0 DESC LIMIT 5;

-- 4. COUNT, SUM, AVG, MIN, MAX, ROUND — посчитать
--    COUNT(DISTINCT поле) — сколько разных значений; LIMIT 5 — показать только первые 5 строк
SELECT COUNT(DISTINCT user_id), MIN(date), MAX(date) FROM activity;

-- 5. GROUP BY — посчитать отдельно по группам
SELECT month, COUNT(DISTINCT user_id) FROM act GROUP BY month;

-- 6. HAVING — оставить нужные группы: кто заходил 60 дней из 90 и больше
SELECT user_id, COUNT(*) FROM act GROUP BY user_id HAVING COUNT(*) >= 60 LIMIT 5;
```

## Даты

Даты записаны текстом в формате `ГГГГ-ММ-ДД`. Такой текст сравнивается правильно, как даты:

```sql
SELECT COUNT(*) FROM newcomers WHERE signup_date >= '2026-09-01';
SELECT COUNT(*) FROM newcomers WHERE signup_date BETWEEN '2026-07-01' AND '2026-07-31';
```

`BETWEEN` включает обе границы.

Все даты одного месяца удобно отобрать по началу текста: `LIKE '2026-07%'` — всё, что начинается с `2026-07`. Знак `%` значит «дальше что угодно».

```sql
SELECT COUNT(*) FROM users WHERE signup_date LIKE '2026-07%';
```

## Приём 1: доля — это `AVG` от условия

Как вчера: условие даёт 1 или 0, среднее от него — доля.

```sql
-- какая доля новичков вернулась хотя бы раз за первую неделю
SELECT ROUND(AVG(back_w1) * 100, 1) FROM newcomers WHERE full_week = 1;

-- какая доля новичков решала задачи в день регистрации
SELECT ROUND(AVG(puzzles0 > 0) * 100, 1) FROM newcomers;
```

## Приём 2: группировать можно по условию

`GROUP BY` принимает не только поле, но и условие. Получится две группы: где условие ложно (0) и где истинно (1).

```sql
-- заходят ли чаще на 7-й день те, кто вернулся на следующий день после регистрации
SELECT back_d1 = 1, COUNT(*), ROUND(AVG(back_d7) * 100, 1)
FROM newcomers
WHERE full_week = 1
GROUP BY back_d1 = 1;
```

Так сравнивают две группы одним запросом. Добавь в `WHERE` ещё одно условие — и сравнишь те же группы на части данных.

## Ловушка: деление целых чисел

В SQLite целое, делённое на целое, — снова целое. Дробная часть отбрасывается:

```sql
SELECT 30 / 400;           -- 0
SELECT 30 * 100 / 400;     -- 7, а не 7.5
SELECT 30 * 100.0 / 400;   -- 7.5
```

Чтобы получить дробь, умножай на `100.0` или `1.0`. Это касается всех процентов в когортном отчёте: `d7 * 100.0 / d0`.

## Арифметика по колонкам

В `SELECT` можно считать прямо по колонкам одной строки:

```sql
SELECT cohort, d0, ROUND(d1 * 100.0 / d0, 1), ROUND(d7 * 100.0 / d0, 1)
FROM cohorts
LIMIT 5;
```

И по суммам — например, сколько партий в среднем приходится на один день одного человека:

```sql
SELECT ROUND(SUM(games) * 1.0 / COUNT(*), 2) FROM act;
```

## Если запрос дал `NULL`

Любая арифметика с `NULL` даёт `NULL`. В `cohorts` пустые ячейки — это `NULL`: удержание дня 30 у когорты, для которой день 30 ещё не наступил, будет `NULL`. `AVG` и `SUM` пропускают `NULL` — считают только по заполненным строкам. Проверь, по скольким строкам на самом деле посчитано твоё среднее: `COUNT(d30)` — число непустых.

Отобрать только заполненные или только пустые строки — `IS NOT NULL` и `IS NULL`. Обычное `= NULL` не работает: сравнение с `NULL` никогда не бывает истинным.

```sql
SELECT COUNT(*) FROM cohorts WHERE d30 IS NOT NULL;   -- когорты, у которых день 30 уже наступил
SELECT COUNT(*) FROM cohorts WHERE d30 IS NULL;       -- ещё не наступил
```
