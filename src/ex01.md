### 1. Период и пользователи

Контрольный вопрос: почему пользователей больше, чем зарегистрировалось за период, и кого из них ты будешь считать новичком?

**Ответ:** пользователей 50148 и новые 4003

```sql
    SELECT month AS activity_month,
    COUNT (user_id) as mau,
    COUNT(DISTINCT CASE WHEN signup_month = month 
            THEN user_id END) AS newcomers,
    COUNT(DISTINCT CASE WHEN signup_month <> month 
            THEN user_id END) AS old_users
FROM act
GROUP BY month
ORDER BY month;
```

### 2. DAU по дням

Контрольный вопрос: что повторяется каждую неделю? Какие из выписанных дней — это повторение, а какие — событие, и как ты их отличил?

**Ответ:**2026-07-01', 1109, 1216.0, 0.91

```sql
WITH d AS (
    SELECT date, COUNT(DISTINCT user_id) AS dau
    FROM activity
    GROUP BY date
),
w as (
    SELECT
            date,
            dau,
            AVG(dau) OVER (ORDER BY date ROWS BETWEEN 3 PRECEDING AND 3 FOLLOWING) AS ma7
    FROM d        
    )
    SELECT
        date,
        dau,
        ROUND(ma7, 0) AS ma7,
        ROUND(dau * 1.0 / ma7, 2) AS ratio_ma7
FROM w
ORDER BY date;   
```

### 5. Средний DAU и липкость

Контрольный вопрос: как менялась липкость, пока рос MAU, и что это говорит о тех, кто пришёл?

**Ответ:**'2026-07', 7917, 1617.7, 0.204

```sql
WITH m as (
    SELECT
        month,
        COUNT(DISTINCT user_id) as mau,
        COUNT(DISTINCT date) as days,
        COUNT(*) as user_days
    FROM act
    GROUP BY month
)
SELECT
    month,
    mau,
    ROUND(1.0 * user_days / days, 1) as avg_dau,
    ROUND(1.0 * user_days / days / mau, 3) as stickiness
FROM m
ORDER BY month;
```

### 6. Новички месяца в MAU

Контрольный вопрос: чья липкость изменилась, а чья осталась прежней?

**Ответ:**'2026-07', 'newcomer', 4003, 31, 18188, 586.7, 0.147


```sql
WITH m AS (
    SELECT
        month,
        CASE WHEN signup_month = month THEN 'newcomer' ELSE 'old' END AS segment,
        user_id,
        date
    FROM act
)
SELECT
    month,
    segment,
    COUNT(DISTINCT user_id) as mau,
    COUNT(DISTINCT date) as days,
    COUNT(*) as user_days,
    ROUND(1.0 * COUNT(*) / COUNT(DISTINCT date),1) as avg_dau,
    ROUND(1.0 * COUNT(*) / COUNT(DISTINCT date) / COUNT(DISTINCT user_id),3) as stickiness
FROM m
GROUP BY month, segment
ORDER BY month, segment;
```

### 7. Кто остался

Контрольный вопрос: если бы новички августа удерживались так же, как новички июля, сколько из них заходило бы в сентябре? Сколько людей мы недосчитались?

**Ответ:**0.066, 27910, 1561, 1841.0, 280.0

```sql
WITH cohort AS (
    SELECT
        c.signup_month,
        COUNT(*) AS size,
        COUNT(DISTINCT a.user_id) AS returned
    FROM newcomers c
    LEFT JOIN act a
        ON a.user_id = c.user_id
        AND a.month = strftime('%Y-%m', date(c.signup_month || '-01', '+1 month'))
    WHERE c.signup_month IN ('2026-07', '2026-08')
        AND c.full_month = 1
    GROUP BY c.signup_month
),
j AS (SELECT * FROM cohort WHERE signup_month = '2026-07'),
a AS (SELECT * FROM cohort WHERE signup_month = '2026-08')
SELECT
    ROUND(j.returned * 1.0 / j.size, 3) as july_retention,
    a.size as aug_cohort,
    a.returned as aug_actual,
    ROUND(a.size * j.returned * 1.0 / j.size) as aug_expected,
    ROUND(a.size * j.returned * 1.0 / j.size) - a.returned as gap
FROM j, a;
```
