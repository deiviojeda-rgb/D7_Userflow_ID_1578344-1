### 1. Что бросается в глаза

Не меньше четырёх находок в абсолютных числах.

```sql
SELECT COUNT(*) AS no_d30 FROM cohorts WHERE d30 IS NULL;
```

### 2. Удержание в процентах

Контрольный вопрос: какая когорта лучшая в штуках и какая — в процентах? Почему картина поменялась?

**Ответ:**

```sql
SELECT cohort, d0,
       ROUND(d1 * 100.0 / d0, 1) AS r1,
       ROUND(d7 * 100.0 / d0, 1) AS r7,
       ROUND(d30 * 100.0 / d0, 1) AS r30
FROM cohorts
ORDER BY cohort;
```

```sql
SELECT cohort, d0, d7 FROM cohorts ORDER BY d7 DESC LIMIT 1;
SELECT cohort, d0, d7, ROUND(d7 * 100.0 / d0, 1) AS r7 FROM cohorts ORDER BY r7 DESC LIMIT 1;
```

Контрольный вопрос: почему границы проходят именно там? Удержание периода можно посчитать от сумм или как среднее процентов когорт — какой способ ты выбрал и насколько отличаются числа? По скольким когортам посчитано удержание дня 7 и дня 30?

**Ответ:** Границы провёл по `d0`. Период начинается там, где размер когорт резко растёт

```sql
SELECT CASE WHEN cohort < '2026-08-07' THEN '1 до волны'
            WHEN cohort < '2026-08-18' THEN '2 первая волна'
            WHEN cohort < '2026-08-28' THEN '3 между волнами'
            WHEN cohort < '2026-09-07' THEN '4 вторая волна'
            ELSE '5 после волн' END AS period,
       COUNT(*) AS cohorts, SUM(d0) AS newcomers,
       ROUND(SUM(d1) * 100.0 / SUM(CASE WHEN d1 IS NOT NULL THEN d0 END), 1) AS r1,
       COUNT(d7) AS n7,
       ROUND(SUM(d7) * 100.0 / SUM(CASE WHEN d7 IS NOT NULL THEN d0 END), 1) AS r7,
       COUNT(d30) AS n30,
       ROUND(SUM(d30) * 100.0 / SUM(CASE WHEN d30 IS NOT NULL THEN d0 END), 1) AS r30
FROM cohorts
GROUP BY period
ORDER BY period;
```

```sql
SELECT CASE WHEN cohort < '2026-08-07' THEN '1 до волны'
            WHEN cohort < '2026-08-18' THEN '2 первая волна'
            WHEN cohort < '2026-08-28' THEN '3 между волнами'
            WHEN cohort < '2026-09-07' THEN '4 вторая волна'
            ELSE '5 после волн' END AS period,
       ROUND(AVG(d1 * 100.0 / d0), 1) AS avg_r1,
       ROUND(AVG(d7 * 100.0 / d0), 1) AS avg_r7,
       ROUND(AVG(d30 * 100.0 / d0), 1) AS avg_r30
FROM cohorts
GROUP BY period
ORDER BY period;
```

### 4. Самая странная находка

Какая календарная дата за ней стоит? Подтверди другим источником — запросом не к таблице `cohorts`.

Контрольный вопрос: это случилось только с новичками или со всеми? Какие числа удержания из-за этого нельзя брать как есть?

**Ответ:** 19 августа. в таблице `act` DAU упал с 2475 18 августа до 935

```sql
SELECT date, COUNT(DISTINCT user_id) AS dau,
       COUNT(DISTINCT CASE WHEN signup_date >= '2026-07-01' THEN user_id END) AS newcomers_dau,
       COUNT(DISTINCT CASE WHEN signup_date < '2026-07-01' THEN user_id END) AS old_dau
FROM act
WHERE date BETWEEN '2026-08-17' AND '2026-08-21'
GROUP BY date
ORDER BY date;
```
