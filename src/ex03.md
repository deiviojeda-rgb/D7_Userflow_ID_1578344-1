## Сигналы

Контрольный вопрос: какой сигнал самый громкий, а какой — самый надёжный? Есть ли среди сигналов такой, который опасно брать в работу, и почему?
**Ответ:** Самый громкий сигнал 5, идея серии дней.

| Сигнал | К какой гипотезе или «не про удержание» | Верю или нет и почему |
|---|---|---|
| 1. Семь поражений подряд | H1, частично H4 | Верю. История одна, но совпадает с данными по `wins0` |
| 2. Не нашёл, где учиться | H3 | Частично. Вход в обучение правда только через меню, но письмо одно |

| 4. Сразу кидают к сильным | H4 | Правдоподобно по механике рейтинга, но рейтингов в данных нет |

## Гипотезы

Контрольный вопрос: какой результат запроса опроверг бы гипотезу? Для гипотезы с самым сильным вердиктом — какое другое объяснение даёт тот же результат?

### H1. После поражения — тупик

Шаг пути:  5, экран после партии.

Если гипотеза верна, в данных будет видно:

Вердикт: не опровергнута

**Ответ:** Без побед на первой неделе вернулись 25,7% из 7781 новичка

```sql
SELECT wins0 = 0 AS no_wins, COUNT(*) AS newcomers,
       ROUND(AVG(back_w1) * 100, 1) AS w1
FROM newcomers
WHERE full_week = 1
GROUP BY no_wins;
```

```sql
SELECT games0, wins0 = 0 AS no_wins, COUNT(*) AS newcomers,
       ROUND(AVG(back_w1) * 100, 1) AS w1
FROM newcomers
WHERE full_week = 1 AND games0 <= 4
GROUP BY games0, no_wins;
```

### H3. Обучение спрятано

Шаг пути: 1 и 7,

Если гипотеза верна, в данных будет видно: новички, которые в день регистрации решали задачи или проходили уроки

Вердикт: не опровергнута

**Ответ:**Задачи или уроки в день регистрации были у 5665 новичков из 19977

```sql
SELECT puzzles0 > 0 OR lessons0 > 0 AS learned, COUNT(*) AS newcomers,
       ROUND(AVG(back_w1) * 100, 1) AS w1
FROM newcomers
WHERE full_week = 1
GROUP BY learned;
```

### H4. Первый рейтинг слишком высокий

Шаг пути: 4,

Если гипотеза верна, в данных будет видно: в первый день новички проигрывают чаще

Вердикт: не проверить этими данными.

**Ответ:**Рейтинга игроков и соперников в данных нет

```sql
SELECT day_n >= 1 AS later_days, SUM(games) AS games,
       ROUND(SUM(wins) * 100.0 / SUM(games), 1) AS win_share
FROM act
WHERE signup_date BETWEEN '2026-07-01' AND '2026-08-06' AND day_n <= 7
GROUP BY later_days;
```
