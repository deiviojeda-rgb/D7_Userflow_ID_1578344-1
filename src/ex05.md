## 4. Что измерим

Главная метрика — определение через поля таблицы `newcomers`:

Доля новичков без побед в день регистрации (`wins0 = 0`), которые вернулись хотя бы раз за первую неделю (`back_w1`). Считаем только тех, у кого неделя прошла целиком (`full_week = 1`).

### 4.1 Метрика сейчас
**Ответ:** 40,1% у 853 новичков июля

```sql
SELECT signup_date >= '2026-09-07' AS after_waves, COUNT(*) AS newcomers,
       ROUND(AVG(back_w1) * 100, 1) AS w1
FROM newcomers
WHERE wins0 = 0 AND full_week = 1
  AND (signup_month = '2026-07' OR signup_date >= '2026-09-07')
GROUP BY after_waves;
```

Цель, срок и с кем сравниваем: Цель поднять метрику примерно с 40% до 50%.

Ограничитель — что не должно ухудшиться: Возврат за первую неделю у всех новичков.

### Ограничитель сейчас

**Ответ:** 64,1% у 4003 новичков июля.

```sql
SELECT COUNT(*) AS newcomers, ROUND(AVG(back_w1) * 100, 1) AS w1_all
FROM newcomers
WHERE signup_month = '2026-07' AND full_week = 1;
```
